# My Zombie Shooter Game

THis is a wave-based zombie shooter game. You start with 3 weapons, a pistol, shotgun and machine gun.

You toggle between them using numbers 1,2 and 3.

There really is no end to this and you just keep playing until you die!

Hope you enjoy!
